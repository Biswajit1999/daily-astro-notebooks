# Exploratory flux-space template comparison · 16 November 2026

This follow-on was specified after the primary colour counts and archive matches were available, before computing any template fits. Preserve the preregistered colour-screen result regardless of these fits.

Fit Euclid VIS/Y/J/H and the nearest VIRCAM VIDEO Z/Y/J/H/Ks source within 0.7 arcsec for each image-audited object. Use the PSF-matched Euclid 2-FWHM fluxes and errors, retaining signed forced fluxes when available. For VIDEO require per-band flags of zero and use the published aperture-3 AB photometry and errors. A missing or flagged catalogue flux enters neither as a zero flux nor as an upper limit. This archive access does not derive a local censoring threshold for the missing VIDEO Z measurement. Fit independent nonnegative normalizations for the two survey aperture systems and use a 5% per-band error floor in quadrature. Report the number of valid bands and residuals. Treat F02 as visibly contaminated, regardless of the numerical fit.

Integrate spectra with the documented total instrument responses using photon weighting. Apply the IRSA/S&F Galactic E(B−V) at the cone centre with an R_V=3.1 extinction law. Use the public CWW+Kinney E/Sbc/Scd/Im/SB1/SB2 and Selsing blue-QSO spectral shapes over 0≤z≤3.8 in 0.02 steps. Fit ordinary stars using public stellar libraries and mid-T standards from SpeX as available. SpeX T standards enter only the near-infrared subset where their observed wavelength range covers the core of the band. Compare all families on that same subset, then run a full optical+infrared fit for the families with coverage. Treat Δχ²≤4 profile-grid components as descriptive sensitivity regions, without interpreting them as calibrated confidence intervals. Omit templates with inadequate wavelength coverage. No population prior. These are limited libraries, and no distance is inferred from a template minimum. Check independent public CDFS spectroscopic catalogues for target matches and note whether a matched control sample is feasible. Astropy Planck18 remains the reference cosmology for an independently reliable galaxy redshift.
