# Preregistered protocol · 16 November 2026

## Faint near-infrared colour outliers in Euclid Deep Field Fornax

**Question.** Does any source selected in a faint extension of the published Q1 T-dwarf colour box also fall securely inside the box with PSF-matched aperture photometry from DR1-Foundation? The screened field is a single 0.125-degree radius ICRS cone at (52.933°, −28.0885°), with a geometric area of 0.0491 deg² before masking. This test concerns the reproducibility of measured colours, with zero survivors as a possible outcome.

Use NASA/IPAC IRSA's DR1 MER Deep Survey catalogue. Query all template-fit J_AB in (23, 24] (equivalent to 0.912–2.291 μJy, using 23.9 as the zero point) in the cone. Reject malformed rows, flag duplicate catalogue records by object ID or position within 0.3 arcsec and retain the cleanest highest J signal-to-noise (S/N) primary row. Exclude from the clean sample any nonzero or missing detection or Y/J/H band flags or parent ID other than −1. Require positive template-fit Y/J/H fluxes, positive errors, and S/N ≥10 in each. No VIS detection or Euclid pipeline morphology-probability cut. Retain VIS flags, shapes, rejected detections and signed VIS aperture flux. Sample completeness, local depth variation and selection into the catalogue will be limitations.

Use the published Kiwy et al. Q1 nominal AB box 0.1 < Y−J < 0.9 and J−H < −0.1. The Q1 search limited each band to AB <23. Report how many candidates retain nominal colours in the same box from the 2-FWHM-diameter PSF-matched apertures. Secure survivors must also have positive aperture flux/errors and S/N ≥5 in all three bands, with the distance from each boundary ≥2 propagated standard deviations. Use a fixed 0.03 mag per-band uncertainty floor in quadrature, then add the two band errors for each colour to bound the unknown inter-band covariance. Rank by the smallest signed margin-to-error ratio across all three boundaries. Use the rest of the same clean J-selected sample as the comparison distribution. For nominal stability quote a Wilson 95% interval under a binomial approximation, conditional on the selected rows. The two estimators use the same images and are correlated. The threshold is a stability screen and gives neither a calibrated false-positive probability nor a population completeness correction.

Audit up to three highest-ranked nominal aperture survivors, or the three highest-ranked template candidates if the aperture yields zero nominal survivors. Request actual Euclid MER VIS, Y, J, H and DECam Legacy Surveys DR10 z cutouts on common sky axes, plus Gaia DR3 astrometry, CatWISE2020 W1/W2, and VISTA/VIRCAM VHS DR5 photometry/coverage where available. Record all returned close alternatives, inspect position/PSF/depth/footprint and flag blending, defects, diffraction and persistence when visible or in flags. Ten arcsec Gaia and CatWISE search windows allow inspection for motion and confused neighbors. Astrometric evidence requires a secure match and epoch-aware interpretation. Query IRSA for PHZ, SPE and combined spectra by exact MER ID. Galaxy, quasar, ordinary star, ultracool dwarf and artifact remain alternatives. Meaningful classification requires suitable calibrated spectra or discrimination across bands with response-integrated flux-space templates. If neither is achieved, report classification, redshift and distance as unconstrained. Do not use a galaxy PHZ as a stellar distance or infer a class from an optical non-detection. The reference cosmology for any independently supported galaxy redshift is Astropy Planck18.

## Search scope before candidate extraction

Screened the 12 November 2026 release overview, ESA Explanatory Supplement chapters 9–11 and the Euclid Consortium release publication list. Queried public web indexes restricted to arXiv and ADS, plus the Euclid publication and IPAC pages, using combinations of Euclid, DR1-Foundation, Fornax/Deep Fields, ultracool/brown dwarf, Y/J/H, proper motion and contamination. This was a targeted screen, not an exhaustive bibliographic census. Q1 photometric and spectroscopic studies already searched Fornax and other deep fields. The narrow test here is colour retention across two estimators in a magnitude range excluded by the Kiwy et al. Q1 search, without an optical-detection requirement.
