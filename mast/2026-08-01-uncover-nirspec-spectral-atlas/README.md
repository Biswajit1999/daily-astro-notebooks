# Real HST images and JWST spectra of distant galaxies

What do the calibrated 1D and 2D NIRSpec data look like for six z=7.88 to 13.16 galaxies?

Run `notebook.ipynb` for the complete methods, figures, validation, limitations, and reusable tables. Data: UNCOVER DR4.1 spectroscopy and MAST archive products. Author: Biswajit Jana.
